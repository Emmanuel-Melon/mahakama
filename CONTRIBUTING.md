# Contributing to Mahakama

Welcome to the Mahakama monorepo! We appreciate your interest in making legal knowledge accessible.

## How to Contribute

- **Reporting Issues**: Please use the GitHub issue tracker. Include clear steps to reproduce, expected vs. actual behavior, and environment details.
- **Pull Requests**:
  - Fork the repository and create a feature branch.
  - Keep PRs focused on a single change (either `api` or `frontend`).
  - Ensure all tests pass before submitting.
  - Follow the existing folder structure (API logic goes in `/api`, frontend UI in `/frontend`).
